DarkEye 使用手册（简要）

本页面为 DarkEye 桌面应用的快速上手说明，详细文档可在 GitHub 仓库中查看。

1. 安装与运行

  • 前往 GitHub Releases 页面，下载最新版本压缩包或安装包。
  • 按 Releases 页面中的说明解压或安装，并根据你的操作系统选择对应的运行方式。
  • 首次运行建议先在设置中配置数据存储路径和备份目录。

2. 基本概念

DarkEye 将收藏对象、标签、事件和行为统一管理，通过本地数据库与图谱实现“收藏 + 情报分析”的工作流。

  • 收藏：通过手动录入或爬虫采集，将条目整理进本地库。
  • 标签与人物：为条目添加多维标签，构建偏好画像和关系网络。
  • 记录：对行为进行时间线记录，用于后续的趋势分析与自我量化。

3. 浏览器插件与采集

  • 在 GitHub 仓库中找到 `extensions/firefox_capture` 相关说明。
  • 在 Firefox 地址栏输入 about:debugging，临时加载插件的 manifest.json。
  • 打开支持的网站后，点击工具栏图标或页面中的按钮即可将元数据发送到本地 DarkEye。

4. 数据与隐私

  • 所有数据默认保存在本地 SQLite 数据库中，不上传到云端。
  • 推荐定期在设置中启用或配置备份，防止误删或磁盘损坏导致的数据丢失。
  • 可根据需要使用伪装模式，将窗口样式与文件结构伪装为常规办公软件。

5. 更多文档

更多高级功能（如力导向图、分析报表、自定义脚本等）请访问 GitHub 仓库 中的 README.md 与 docs/ 文档。
